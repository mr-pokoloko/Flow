# My Development Workflow

This workflow outlines the standard steps for development tasks.

## Steps

1. **Analyze Requirements**
   - Read the task description carefully
   - Identify key objectives and constraints
   - Note any specific technologies or frameworks mentioned

2. **Explore Codebase**
   - Search for relevant files and code sections
   - Understand the existing structure and patterns
   - Identify where changes need to be made

3. **Plan Implementation**
   - Create a todo list for tracking progress
   - Break down the task into manageable steps
   - Prioritize critical path items

4. **Implement Changes**
   - Make minimal, focused edits
   - Follow existing code style and patterns
   - Test changes as you go

5. **Verify & Review**
   - Check for any errors or warnings
   - Ensure all requirements are met
   - Clean up any temporary code or comments

6. **Complete**
   - Mark all todo items as completed
   - Provide summary of changes made
   - End with clear completion status

## Notes

- Always use the todo_list tool to track progress
- Prefer edit tool over write_to_file when modifying existing code
- Use multi_edit for multiple changes to the same file
- Follow the existing code style and conventions
- Test changes thoroughly before completing
